# أوامر البوت v3.0

## أساسية
- `/start` — لوحة اختيار الطفل
- `/menu` — لوحة التحكم الرئيسية
- `/live` — الموقع الحالي
- `/report` — التقرير اليومي الآن

## المسارات
- 🕐 مسار 1/6/24 ساعة (GPX + KML + CSV)
- 🗺️ خريطة HTML تفاعلية
- 🔥 خريطة حرارية
- 🏠 اكتشاف الأماكن المتكررة
- 📅 ملخص اليوم

## السياج الجغرافي
- `/fence اسم خط_العرض خط_الطول نصف_القطر`
- مثال: `/fence المدرسة 33.3152 44.3661 200`

## أوامر عن بعد (تُنفّذ عند عودة الاتصال)
- `/cmd locate` — تحديد الموقع فوراً
- `/cmd restart` — إعادة تشغيل الخدمة
- `/cmd sync` — مزامنة كاملة
- `/cmd sos_off` — إيقاف الصافرة

## تنبيهات خلفية تلقائية
- 🔋 بطارية < 15%
- 🚗 سرعة > 60 km/h
- 🚧 خروج من سياج
- 🆘 ضغط زر SOS
- 📊 تقرير يومي الساعة 20:00 (بغداد)
- 📈 تقرير أسبوعي كل أحد

## تنقية ذكية
- Douglas-Peucker: تقليل النقاط 60-90%
- استبعاد نقاط accuracy > 50m
- استبعاد السرعات المستحيلة > 200 km/h
