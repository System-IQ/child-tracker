# Child Tracker - نظام حماية الأطفال

نظام تتبع أطفال يعمل بدون إنترنت ويرسل المسار تلقائياً عبر تلجرام.

## المكونات
- android_app/ : تطبيق الطفل (Flutter + Tracelet)
- bot/         : بوت تلجرام للتحكم (Termux)
- .github/     : بناء APK تلقائياً

## ⚠️ تحذير قانوني
هذا المشروع للأغراض الأبوية المشروعة فقط. تتبع الأشخاص دون موافقتهم غير قانوني.
